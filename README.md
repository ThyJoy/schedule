# Расписание — мобильное приложение из файла Word

PWA (веб-приложение, которое ставится на телефон как обычное): читает расписание
из `.doc` или `.docx`, показывает пары по дням с учётом чётной/нечётной недели и
периодов «с … по …», работает офлайн.

## Структура

```
docs/                 ← само приложение (GitHub Pages публикует эту папку)
  index.html, style.css, app.js
  parser.js           ← разбор .doc/.docx → JSON (работает в браузере и в Node)
  schedule.json       ← встроенное расписание (из текущего файла)
  sw.js, manifest.webmanifest, icons/   ← офлайн и установка на телефон
  vendor/             ← cfb (чтение .doc) и jszip (чтение .docx), MIT/Apache
tools/parse.js        ← тот же разбор из командной строки
```

## Как обновлять расписание

- **С телефона:** ⚙ Настройки → «Загрузить новый файл» → выбрать `.doc`/`.docx`.
  На Android можно ещё «Поделиться» файлом из Telegram/почты → «Расписание».
  Файл разбирается прямо на телефоне, никуда не отправляется.
- **Встроенное расписание** (то, что видят все при первом открытии):
  ```
  npm i cfb jszip @xmldom/xmldom      # один раз
  node tools/parse.js "новый файл.doc" docs/schedule.json
  ```
  и сделать `git commit` + `git push` — сайт обновится сам.

## Запуск локально

```
cd docs && python3 -m http.server 8000
```
Открыть http://localhost:8000. Опубликованная версия: https://thyjoy.github.io/schedule/ С телефона в той же Wi-Fi сети можно открыть
`http://<IP компьютера>:8000`, но установка и офлайн-режим работают только по HTTPS —
для этого приложение нужно выложить на хостинг (GitHub Pages, Netlify, Vercel — бесплатно).

## Установка на телефон (после выкладки по HTTPS)

- **Android (Chrome):** меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## Что понимает парсер

Таблица с заголовком «N курс» и колонкой «Ауд.» справа от каждого курса, дни недели
в первой колонке, время пар («09.30-11.00») во второй. В ячейках распознаются:
`(четная неделя)` / `(нечетная неделя)`, периоды `(с 01.10.26 по 18.11.26)`,
несколько предметов в одной ячейке (с разными аудиториями), преподаватели,
примечания в скобках. Объединённые ячейки разворачиваются.

Начало занятий берётся из файла (самая ранняя дата «с …», сейчас 01.10) — до неё
пары не показываются. Неделя, в которую начинаются занятия, — первая (нечётная);
дату и чётность можно поправить в настройках.
